# Pocket Evo 站点导入插件

一个用于 Pocket Evo App 快速添加站点的 Chrome 扩展。它可以从已登录的站点读取导入所需的配置，并生成供 Pocket Evo 手机端扫码导入的二维码。

## 开发

需要 Node.js 24 或兼容版本。

```bash
npm install
npm test
npm run build
```

构建产物位于 `dist/` 目录。

## 安装

1. 运行 `npm run build`；
2. 在 Chrome 中打开 `chrome://extensions`；
3. 开启“开发者模式”；
4. 点击“加载已解压的扩展程序”；
5. 选择构建后的 `dist/` 目录。

插件需要 Chrome 132 或更高版本。打开 PT 站页面后，点击插件图标即可在侧边栏中读取和编辑配置。

## 隐私与安全

- 插件不会把站点配置或凭据发送到网络；
- 配置和凭据在侧边栏内存中处理；全屏二维码通过浏览器会话存储一次性传递，读取后删除，未读取的数据五分钟后失效并由后续浏览器事件清理；
- Cookie、Token、UID 和 Passkey 默认遮挡；
- 二维码包含站点登录凭据，请勿截图或分享；
- 二维码的压缩编码不是加密。

为完成核心功能，插件需要读取当前 HTTP/HTTPS 站点的页面和 Cookie 数据。

## 1.6.0 界面与交互重构

- 使用 Pocket Evo 正式品牌图标、Phosphor 图标、Montserrat 字体和共享深浅主题；支持中文、英文、法语、德语和西班牙语。
- 读取、权限、编辑、错误、二维码、全屏及确认弹窗共用组件；刷新有未保存修改时先确认。
- 分类页面的添加按钮位于标题下方；新页面名称留空，填写后即时更新校验。
- 高级设置始终展开。站点和下载器标签初始为空；预设标签与手动输入共用一个输入框，支持中英文逗号、去重、直接删除。
- 文本编辑实时保存到草稿，保留光标、中文输入与按钮焦点；提供可恢复的读取和二维码错误提示。
- 添加页面防止重复请求与过期结果回写，最多50页；页面导航和Cookie账号隔离增强。
- 严格匹配App导入器的地址、入口和数据大小限制；二维码支持窄侧栏，界面跟随系统浅色/深色。

### 本地交互预览

运行 `npx vite --host 127.0.0.1 --port 4173`，打开 `/test/preview.html`。
预览使用合成站点与凭据，加载正式的收集、编辑、校验及二维码代码，可比较320/400/560px布局（`lang` 支持五语言、`theme` 支持 light/dark）；全屏打开单独的合成数据夹具；这不代替真实 Chrome 扩展或手机扫码验收。可在 `preview-frame.html` 加 `lang=de&theme=dark&scenario=open-error` 检查失败恢复。开发预览不会打包进插件。

### 更新已安装版本

构建后在 Chrome 的扩展管理页点击本插件的重新加载按钮，关闭旧侧栏后重新打开。新安装时加载 `dist/`；收到ZIP时先解压，再选择包含 `manifest.json` 的目录。
