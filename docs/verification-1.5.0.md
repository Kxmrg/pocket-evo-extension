# Pocket Evo 站点导入插件 1.5.0 验收记录

日期：2026-11-23。

本轮保留用户确认的布局：分类页面标题、标题下方双添加按钮、新页面名称留空、空名称提示“请输入页面名称”、高级设置常展开、预设与手动标签共用输入框、站点和下载器标签不自动选择。

## 修复与优化

- 表单文本实时进入草稿，原位更新校验，避免失焦重建表单吞掉点击；中文输入和光标保留。
- 预设标签、凭据显示按钮保留键盘焦点；架构菜单支持方向键、Home/End、Escape、失焦与点击外部关闭。
- 标签统一支持中英文逗号、首尾空白与精确去重，清空后不输出空数组。
- 异步加页防重复并限制50页；刷新、修改地址或架构后的旧请求不回写；错误提示不阻止导出原有有效配置。
- 地址输入的临时无效状态不会清空已获取的 Piggo 凭据；恢复有效地址后可继续导入。
- 读取与加页检查快照来源，Cookie读取使用实际快照路径；Cookie store缺失不退回其他账号，host-only Cookie不跨子域混用。
- 原始站点地址、空片段、MT数字上界、UNIT3D规范化路径、App解压256 KiB上限均按导入契约校验。
- 侧栏及全屏二维码错误有恢复提示，重试成功清理旧错误。
- 全屏传递数据一次性读取删除、五分钟失效，并在相关浏览器事件清扫过期数据。失效保证不等于精确时刻物理删除。
- 修复320px侧栏二维码溢出、长步骤及字段内容截断；增强焦点与文字对比度，跟随系统深浅色，二维码保持白底。
- package、lockfile、manifest 与界面版本统一为1.5.0。
